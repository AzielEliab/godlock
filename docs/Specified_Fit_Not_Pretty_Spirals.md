A spiral is not a specification. A pretty ratio is not a functional mapping.

### B — Biological object

The object is not “life is complicated.” It is the joint system:

- digital sequence
- mapping table
- machines that implement the mapping
- error repair
- machines encoded in the sequences

Compiler + source. Code + reader. S without R is a polymer. R without S is a machine with no program. The historical “frozen accident” story for the codon table is a confession that necessity did not pick the table. Joint origin is the problem.

RNA-world and like programs are research hopes, not demonstrated unguided routes to coded translation.

Concede Darwin after a replicator exists. Vestigial, suboptimal, or jury-rigged features speak to design quality or history. They do not show that undirected chemistry wrote a code.

Cosmology and anthropic fine-tuning are a different book. Physics does not write a codon table. Do not spend biological capital on a cosmology dispute. Multiverse replies belong on ledger C, not ledger B.
